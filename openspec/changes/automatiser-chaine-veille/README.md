# automatiser-chaine-veille

Automatise la chaîne de veille sécurité : synchronisation horaire des sources d'avis, empreinte du contenu normalisé, import quotidien des inventaires depuis les forges, recorrélation à l'import, projets multi-dépôts, état de traitement des impacts, abonnements suspendus et mesure de performance API/MCP (décisions J1 à J8 du porteur du projet, 2026-11-19).
